🌿 Finora — POC API

Bukti konsep komunikasi GitHub Pages ↔ Apps Script (PRD §6.2). Simpan file ini di repo GitHub Pages (atau buka lokal) dan isi URL Web App Anda.

Contoh uji cepat setelah login — salin ke kotak JSON (ganti TOKEN):
{"action":"account.create","request_id":"t1","account_name":"BCA","account_type":"BANK","opening_balance":5000000,"opening_date":"2026-12-01","token":"TOKEN"}

⚠️ Selalu kirim Content-Type: text/plain agar tidak memicu preflight CORS yang tak didukung Apps Script (token dikirim di dalam body JSON).
